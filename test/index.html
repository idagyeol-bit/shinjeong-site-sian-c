현장 진행 방식

  1. 01사전 확인

    입구, 내부 구조, 잔류물을 먼저 확인합니다.

  2. 02로봇 투입

    로봇이 설비 안의 위험 물질을 먼저 회수합니다.

  3. 03원격 조종

    작업자는 설비 밖 제어 차량에서 CCTV를 보며 조종합니다.

  4. 04마무리·처리

    위험이 줄어든 뒤 작업자가 마무리하고, 회수물은 탈수해 처리합니다.
